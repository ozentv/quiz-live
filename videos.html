Fabriquer de nouvelles vidéos
  1. Ouvre la page de fabrication (connecte-toi à GitHub si besoin).
  2. Appuie sur « Run workflow ». Laisse tout pour faire une vidéo de chaque thème (ou écris des thèmes, ex : om psg football), puis le bouton vert « Run workflow ».
  3. Reviens ici plus tard (environ 3 minutes par vidéo, presque 2 h pour tous les thèmes) : les nouvelles vidéos apparaissent dans « À télécharger ».
